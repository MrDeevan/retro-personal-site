# Welcome to the Grid 🎮

A cyberpunk-inspired, retro-techy personal portfolio website with neon aesthetics and interactive effects.

## ✨ Features

- **Neon Cyberpunk Aesthetic** - Glowing neon colors with synthwave vibes
- **Scanline Effects** - Classic CRT monitor scanline animation
- **Glitch Animations** - Retro glitch effects on hover
- **Smooth Scrolling** - Fluid navigation experience
- **Responsive Design** - Works on all devices
- **Terminal Vibes** - Monospace fonts and terminal-style UI
- **Particle Effects** - Floating animated backgrounds
- **Keyboard Shortcuts** - Alt + H/A/P/C for quick navigation

## 🎨 Color Scheme

- **Primary Neon**: `#00ff88` (Bright Green)
- **Secondary Neon**: `#ff00ff` (Magenta)
- **Tertiary Neon**: `#00ffff` (Cyan)
- **Background**: Dark gradient with retro vibes

## 🚀 Quick Start

1. Clone the repository
```bash
git clone https://github.com/MrDeevan/retro-personal-site.git
cd retro-personal-site
```

2. Open `index.html` in your browser
```bash
open index.html
# or
start index.html
```

3. Customize the content:
   - Edit your name and info in `index.html`
   - Update project details in the Projects section
   - Add your contact links
   - Modify colors in `styles.css` `:root` variables

## 📝 Customization

### Change Neon Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-neon: #00ff88;      /* Main neon color */
    --secondary-neon: #ff00ff;    /* Accent color */
    --tertiary-neon: #00ffff;     /* Highlight color */
    --bg-dark: #0a0e27;           /* Dark background */
    --bg-darker: #050810;         /* Darker background */
}
```

### Add Your Projects

Update the projects section in `index.html`:

```html
<div class="project-card">
    <div class="project-header">YOUR_PROJECT.exe</div>
    <p>Project description here</p>
    <div class="project-tech">
        <span class="tech-tag">TECH1</span>
        <span class="tech-tag">TECH2</span>
    </div>
    <a href="https://github.com/yourlink" class="project-link">$ VIEW CODE</a>
</div>
```

### Update Contact Links

Find the contact section and add your actual links:
- Replace `your@email.com` with your email
- Update GitHub, Twitter, LinkedIn URLs
- Add more social links as needed
